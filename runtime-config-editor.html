运行配置编辑器

解密并编辑后端加密运行配置（data/runtime-config.enc，AES-256-GCM 信封）。导出后覆盖原文件并重启后端生效。

纯浏览器本地运算，不发起任何网络请求，密钥不会离开本机
  1. 1粘贴密钥与配置
  2. 2编辑配置项
  3. 3导出加密文件

粘贴密钥与加密配置

密钥即 runtime-config.key 的完整内容（43 位 base64url 字符）；配置即 runtime-config.enc 的完整 JSON。也可以点击右侧"从文件加载"直接选择文件。

编辑配置项

直接修改右侧输入框的值即可；琥珀色标记的是敏感项（secret / password / apikey / masterkey / pepper）。键名不可修改，如需调整请删除后重新添加。

导出

将下面的 JSON 内容完整覆盖写入 runtime-config.enc（或直接下载），然后重启后端进程。

注意：覆盖原文件前建议先备份；导出使用了新的随机 IV，但密钥保持不变——请确保 runtime-config.key 与该密文配对。若缺少 bootstrap.completed 标记会自动补为 true。修改需重启后端才生效。
